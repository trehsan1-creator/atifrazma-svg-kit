از وضعیت بحرانیِ تحویل‌گرفته تا سه جزء کنترل‌شده و قابل‌به‌روزرسانی

دستگاه RG110 یک ردیاب GPS صنعتی است: ماژول SIM868 ارتباط سلولی (GSM/GPRS) و ماهواره‌ای (GPS، GLONASS، BeiDou و Galileo) را فراهم می‌کند و حافظهٔ W25Q32JV (۴ مگابایت، SPI NOR) تله‌متری را نگه می‌دارد. فریم‌ور بدون HAL و بدون RTOS، روی یک superloop ۸۸ مرحله‌ای و وقفهٔ تایمر TIM6 با نرخ ۱ هرتز اجرا می‌شود.

این دستگاه حدود دو ماه پیش در وضعیت بحرانی تحویل گرفته شد: پس از آپدیت OTA از کار می‌افتاد، ساعت‌ها offline می‌ماند و تنظیمات مشتری را از دست می‌داد. فریم‌ور دریافتی (Main B1.05.xx و FOTA 0.2.5) بررسی، اصلاح و گسترش یافت و سه جزء تحویل داده می‌شود: Main B1.06.60، بوت‌لودر FOTA 02.06 و ابزار FLASHER_913_02.06. اکنون دستگاه در وضعیت کنترل‌شده است، از راه دور آپدیت می‌شود و با Black Box تشخیصی قابل عیب‌یابی است.

تغییر ناسازگار ـ پیش از آپدیت اجرا شود

فهرست شماره‌های مجاز در نسخهٔ جدید به‌صورت پیش‌فرض خالی است. شماره‌های هر دستگاه را پیش از آپدیت یادداشت کنید و پس از آن با SMS دوباره ثبت کنید (RG-17).

void Sim_USART_Recover(void)
{
    NVIC_DisableIRQ(Sim_USART_IRQn);           /* interrupts off */
    Sim_USART->CR1 &= ~USART_CR1_UE;           /* disable USART */
    RCC->APBRSTR2 |= RCC_APBRSTR2_USART1RST;   /* peripheral reset via RCC */
    (void)RCC->APBRSTR2;                       /* read-back fence */
    RCC->APBRSTR2 &= ~RCC_APBRSTR2_USART1RST;  /* release reset */
    NVIC_ClearPendingIRQ(Sim_USART_IRQn);
    Sim_USART_Config();
    Sim_RX_Flush();
    simUsartRecovers++;                        /* reported in io211 */
}
